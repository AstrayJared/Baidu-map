# 当前算法版本：E8.3 POI局部发现

版本日期：2026-09-16。本阶段优化到此冻结。当前实现为E8.2径向搜索、局部多边界重建，加E8.3 `discover` POI触发局部发现；400次构圈上限作为本次同预算比较档位。本文集中记录当前实现、实验结论和复现方法，不携带历轮实验报告。

## 实现与接口

- `tools.endpoint_multicross_boundary.compute_multicross_boundary`：E8.2构圈核心，先进行方向搜索，再细化异常局部区域；以实际路线端点保存正负证据。未完成区域继续标记未知。
- `tools.endpoint_e83_poi.run_task`：当前联合任务入口，使用 `shared=True, poi_policy='discover'` 启用新版。构圈预算和POI核验预算分别传入、分别计数，总调用包含失败与重试。该联合实验入口目前仅接受离线Provider。
- `tools.endpoint_e83_guided_experiment`：冻结场景、候选目录、源码哈希与完整账本；默认阻断网络。`--baseline-budget` 可指定与新版一致的对照预算，避免把新版400误比成基线300。
- `life_circle.models.RouteObservation`、`life_circle.providers.BaiduProvider`：在请求点因端点偏移被拒绝时，保留实际端点耗时和偏移距离；原请求点的有效性仍由既有规则控制。实际端点证据不能直接当作请求POI入口的耗时。

新版在基本方向完成后执行既定POI任务。普通POI只有在实际可达端点位于当前候选面外且距离超过25米时，才提前导入并触发关联三角区域的局部搜索。保留原最长混合边顺序，不直接填满三角面或猜测连接走廊。其他普通证据在构圈结束后回写，负证据继续约束最终圈面。

几何布尔运算使用1e-7米精度网格；地理坐标输出修复必须同时满足面积及空间偏移保护，往返容差1e-6米。保留孔洞、多分量和未知区域，不进行视觉平滑或擅自填洞。

本PR保存当前可复现算法及所需基础模块。既有生产API、前端流程和设施1000米规则未切换到本联合实验入口，也未修改生产默认预算。早期模块作为当前实现的依赖保留；实验策略均需显式选择，`early`、`guided` 等消融选项不是当前推荐配置。

## 400次同预算对照

六类合成场景，各有四种候选数/核验额度组合：20/20、50/50、200/50、200/200。每个设置运行E8.2策略基线和新版两臂，共24个配对、48组、18488次合成调用；真实API调用0。每次独立冷启动，源码、候选和阈值固定。基线包含既有数值几何修复。

质量保护：IoU下降超过0.01，或任一方向外环P95误差增加超过10米即触发回归。400档24个配对均未触发该阈值；非法/失败几何0组、已知负证据覆盖冲突0组、错误分钟数0。同任务两臂设施指标完全一致，但入口吸附无法确认的设施仍为待确认，不等于全部设施已完成核验。

400是构圈上限，另有POI核验额度；提前停止时不会用满。24个设置基线总调用9148、新版9340，增加192次（2.10%），没有降本收益。未触发退化阈值也不代表所有指标改善。窄突出主要发现了部分末端，主体通道仍未完整恢复。

300档仍有1/24设置触发回归，250档有7/24；因此不能把低预算档作为已证明等质量的替代。没有使用独立留出集，当前结果只支持开发场景内的比较，不宣称泛化精度或统计显著性。

## 真实结果的适用范围

国定一真实运行目前验证的是原E8.2：300次耗时20.58秒、圈面1.034 km²、局部未知19.45万m²；400次耗时27.58秒、圈面1.056 km²、局部未知15.98万m²。两轮请求均成功，圈面有效，已测超时端点内部覆盖为0，均因预算耗尽而未完全收敛。

与历史1200次圈面的IoU分别为94.26%、96.62%。历史1200次结果不是独立真值，重合度不等于真实准确率。新版联合任务尚无国定一真实对照，不能把E8.2真实结果写成新版已经线上验证。

## 复现与验证

依赖沿用 `backend/requirements.lock.txt` 与 `life-circle-algorithm/pyproject.toml`。安装及运行环境准备参照现有后端README，不新增依赖。

从仓库根目录，在已准备好的Python环境执行（输出目录必须尚不存在）：

```powershell
$env:PYTHONPATH="$PWD/backend;$PWD/life-circle-algorithm/src"
$env:PYTHONDONTWRITEBYTECODE='1'
python -m tools.endpoint_e83_guided_experiment --output 'D:/CodexOutputs/e83-current-400' --budgets 400 --baseline-budget 400 --policies discover
python -m pytest backend/tests/test_endpoint_e83_guidance.py backend/tests/test_endpoint_e83_poi.py backend/tests/test_endpoint_geometry.py backend/tests/test_endpoint_e83_sampling.py -p no:cacheprovider --basetemp='D:/CodexOutputs/e83-current-tests'
```
